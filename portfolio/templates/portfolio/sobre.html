Arquitetura MVT do Django

O Django segue o padrão MVT (Model–View–Template), uma variante do padrão MVC. O Model define a estrutura dos dados e interage com a base de dados. A View contém a lógica de negócio e decide o que mostrar. O Template é o HTML que é renderizado e enviado ao browser.

📷 Fotografia do diagrama MVT em papel será inserida aqui.

Model

Define as tabelas da base de dados. Cada classe em models.py corresponde a uma tabela SQLite.

View

Recebe o pedido HTTP, consulta os models, prepara o contexto e devolve o template renderizado.

Template

Ficheiro HTML com tags Django que renderiza os dados recebidos da view para o utilizador.

URL Dispatcher

O urls.py faz o mapeamento entre os endereços web e as views correspondentes.

O Git e o GitHub foram usados para controlo de versões ao longo do desenvolvimento.
